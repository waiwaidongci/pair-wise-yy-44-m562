# 巡演舞台调度与走位编排工作台

面向剧院巡演团队的舞台执行工作台，覆盖演员与道具调度、舞台走位、执行提示、留言协同、版本回退、基线锁定和演出文档打印。

## 技术栈

Vue 3 + Element Plus + Pinia + Vue Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62044`。

## 核心工作流

- 在舞台平面图中选择走位，编辑入场点、退场点、路线节点和触发时机。
- 在同一脚本时间线中维护灯光、音响、道具与执行提示。
- 添加部门留言、标记问题并生成修改版本；撤销、重做和离线草稿会自动保存。
- 锁定演出基线，并从打印中心输出走位表和执行清单。

## 场地适配（巡演窄台口）

主数据只保存原场地（上海大剧院 16m × 12m）的归一化坐标（0~100），作为只读基线；
每个巡演场地单独登记勘测数据并形成各自的可打印执行版本。

- **场地登记**（场地适配页）：台口宽、台口深、侧幕安全余量、升降台禁入区与乐池范围（实测米制，原点为上场中线）。
  基线场地勘测与几何只读，巡演场地可增删危险区、修改尺寸。
- **换算**：切换场地后，入场点、路线节点、退场点按实测尺寸换算为米制坐标，平面图按真实宽高比绘制并叠加危险区。
  首次需显式“按实测尺寸换算”，换算结果进入该场地的执行版本。
- **危险区暂缓锁定**：落在乐池、升降台禁入区或台口外（侧幕盲区）的节点单独列出，所在场景禁止锁定；
  靠近侧幕余量带的节点仅预警，不阻止锁定。可在场地版本上做米制节点微调或“移到最近安全点”，
  修正只属于该场地，不回写基线。
- **只重算受影响场景**：演员、道具或走位（含责任部门）变化后，仅受影响场景标记“待重算”；
  勘测尺寸 / 危险区变化影响全剧。重算与初次换算均有日志。
- **打印**：打印中心可为任意勾选场地分别输出执行清单与 CSV（含实测坐标、危险区单列、场景锁定/待算状态）。

### 实测坐标系

- 原点：台面上口中点（上场中线与上场边沿交点）
- `x`：向舞台右为正，台口内 `[-台口宽/2, +台口宽/2]`
- `d`：向观众方向为正，台面内 `[0, 台口深]`，乐池 `d > 台口深`
